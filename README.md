🏨 Hotel Management System

This project is a web-based Hotel Management System designed to handle day-to-day hotel operations efficiently. It focuses on managing room bookings, guest records, and availability through a digital system.

Unlike typical online booking systems, this application is built around hotel reception operations, where staff manage customer entries, bookings, and check-ins directly.

The system also includes an admin panel for overall control and management.

📌 What this project does

The application provides a centralized system for hotel staff to manage guests, room availability, and bookings. It replaces manual registers with a digital solution, making the process faster and more organized.

There are two main parts of the system:

* Reception side – used by hotel staff for handling guests and bookings
* Admin side – used for managing rooms, records, and system data
  
⚙️ Main functionalities

🧾 Reception Side:
  
* Reception login syste
* Check room availability
* Add guest details
* Create new bookings/check-ins
* View and manage booking records
* Handle check-outs or cancellations
* Search guest or booking details

🛠️ Admin Panel
* Dashboard overview
* Add, update, and delete rooms
* Manage room availability
* view all guest records
* Monitor booking history
* Manage system data and records
   
🛠️ Technologies used
* Frontend: HTML, CSS, JavaScript
* Backend: PHP
* Database: MySQL
* Tools:
    * Composer (if used)
    * PHP database libraries
 
🔄 How the system works

* Reception staff logs into the system
* Checks available rooms
* Enters guest details
* Creates a booking or check-in
* Data is stored in the database
* On checkout, records are updated
* Admin monitors and manages all records

📂 Project structure

index.php                # Home / login page
login.php                # Authentication
dashboard.php            # Reception dashboard
admin/                   # Admin panel
rooms.php                # Room management
booking.php              # Booking/check-in module
checkout.php             # Checkout handling
database/                # Database configuration
